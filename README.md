# spending-assistant

PoC de um assistente de gastos: API em NestJS que registra despesas, acompanha o limite mensal e dispara avisos de forma assíncrona por fila, com painel web e servidor MCP.

> ⚠️ **Projeto em construção.** É uma prova de conceito feita para estudo, com dados fictícios. O README completo (arquitetura, como rodar, decisões e limitações) vem na etapa final.
